# pipelinemd

## Attribution

Nothing pushed to this repository is attributed to Claude Code. That covers
commit authors and trailers, pull request descriptions, issue and pull request
comments, reviews, and review replies.

Concretely, none of the following may appear:

- a `Generated by Claude Code` footer or a link to claude.ai/code
- a `Co-Authored-By: Claude ...` trailer
- a `Claude-Session:` trailer
- `Claude` as a commit author

Commits are authored by the repository owner.

### Comments need an extra step

The footer on issue and pull request comments is appended server-side when the
comment is created, so it cannot be suppressed at post time. Create the
comment, then immediately edit it to remove the footer, and re-read the comment
afterwards to confirm it is gone. Editing does not re-append it.
